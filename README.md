# DOVETALE &ndash; Business &amp; Marketing Systems

A high-performance corporate web suite for **Dovetale**, engineered with an editorial Swiss / Nordic luxury aesthetic inspired by **Leroux**.

## Overview

Dovetale Marketing engineers the technical infrastructure behind modern digital marketing:
- **10 Core Infrastructure Pillars**: Unified Data Layer, Server-Side CAPI, Bi-Directional CRM Sync, Lifecycle Automation, CRO Experimentation Matrix, Multi-Touch Attribution, Dynamic Creative Ops, CDP & Identity Resolution, Executive BI Dashboards, and Technical Governance.
- **Commercial Packages**: Foundation System, Growth Infrastructure, and Enterprise Scale Engine.
- **Delivery Framework**: 4-Stage Sprint Lifecycle with a 42-point inspection matrix and guaranteed 4-hour diagnostic SLA.

## Architecture & Styling

- **Typography**: Editorial display headers set in `DM Sans` with letter-spacing and signature muted word accents.
- **Component Engine**: Custom JavaScript motion engine (`js/dovetale-engine.js`) providing:
  - Full-bleed hero carousel with automated progress indicator and slide counter
  - Interactive process steps with dynamic photography switching
  - Editorial testimonial quote carousel
  - Live technical specification diagnostic booking form
  - Responsive mobile drawer navigation
